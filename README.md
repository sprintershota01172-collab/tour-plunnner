# mālie — Honeymoon Planner

ホノルル旅行の「行きたい場所」を集め、15分刻みで旅程を組み立てるスマホ向けPWAです。

## 公開後の使い方

1. GitHub Pagesの公開URLをiPhoneのSafariで開きます。
2. Safariの共有メニューから「ホーム画面に追加」します。
3. 旅行設定、行きたい場所、旅程を使います。旅程と写真は端末内のIndexedDBに保存されます。

## 機能

- 行きたい場所の登録、カテゴリ、所要時間、優先度、予約状況、メモ
- 写真の取り込み（端末で長辺1600px程度に縮小）
- 15分刻みのパズルボード、日付移動、旅程ビュー
- Googleマップへのリンク、テキスト/画像/JSON共有、JSONインポート
- 一度開いた後のオフライン表示

## 注意

このリポジトリは静的なGitHub Pagesで公開します。URLからのページ情報自動取得にはサーバーレス関数の別ホスティングが必要です。関数を設定していない間も、URLの保存、場所の手入力、旅程作成は利用できます。
